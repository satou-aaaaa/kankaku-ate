# 感覚器官あて（kankaku-ate）

刺激や感覚器官の説明（光を受け取る・音を受け取る・痛みや熱さを感じる など）を読んで、感覚器官（目・耳・鼻・舌・皮膚）を当てる1日5問の学習ゲーム。正解したら「何を感じる？」（見る・聞く／嗅ぐ・味わう／痛みや熱さを感じる）も選ぶ。中学2年理科「刺激と反応」。

遊ぶ: <https://satou-aaaaa.github.io/kankaku-ate/>

- 中身は千葉県教育委員会の理科の問題、枚方市立中宮中学校の学習指導案（大阪府教育センター）、群馬県教育委員会の学習指導案、札幌市教育委員会の学習課題で確かめたことだけです。
- 病気や視力・聴力の検査のことは扱いません。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。ただし結果画面で X・LINE の共有を押したときだけ、結果の共有文（正解の数など）がそのサイトに渡ります。
